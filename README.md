💳 Plans & Prices

A clean and modern pricing plans landing page created to showcase subscription options in a visually organized and user-friendly way. The project focuses on layout structure, pricing presentation, and simple interactive effects using vanilla web technologies.

🌐 Live Demo
Repository: https://github.com/leoreyes07/plans-n-prices
Live Website: https://leoreyes07.github.io/plans-n-prices/
✨ Features
Pricing plan cards
Modern UI layout
Clean typography
Hover animations and transitions
Structured pricing comparison
Simple and lightweight implementation

🚀 Getting Started

Clone the repository:

git clone https://github.com/leoreyes07/plans-n-prices.git

Navigate into the project directory:

cd plans-n-prices

Open the index.html file in your browser.
